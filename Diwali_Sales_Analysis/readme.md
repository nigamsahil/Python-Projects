# Diwali Sales Analysis

This project analyzes Diwali sales data to understand customer purchasing behaviour and sales trends.

## Key Insights

* Female customers generated higher sales.
* The 26–35 age group purchased the most.
* Uttar Pradesh, Maharashtra, and Karnataka had the highest sales.
* Food, Clothing, and Electronics were the top categories.
* IT, Healthcare, and Aviation customers spent the most.

## Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn and Google Colab.
